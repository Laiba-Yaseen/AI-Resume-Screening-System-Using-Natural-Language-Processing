# 📄 AI Resume Screening System Using Natural Language Processing

## 📌 Project Overview

The **AI Resume Screening System** is an NLP and Machine Learning-based application that automates the resume evaluation process. The system compares a candidate's resume with a job description and generates a matching score based on skills, qualifications, and relevant keywords using **TF-IDF Vectorization** and **Cosine Similarity**.

This project demonstrates the practical application of **Artificial Intelligence, Natural Language Processing, and Recruitment Automation**.

---

## 🎯 Project Objective

To automate candidate screening and improve the efficiency of the recruitment process by intelligently matching resumes with job requirements.

---

## ✨ Key Features

* 📄 Automated resume and job description analysis
* 🧠 NLP-based text processing
* 📊 Resume-to-job matching score calculation
* 🔍 TF-IDF and Cosine Similarity implementation
* ⚡ Fast and efficient candidate evaluation
* 💻 Google Colab implementation

---

## 🏗️ Project Workflow

1. Input the candidate resume and job description.
2. Perform text preprocessing.
3. Convert text into numerical vectors using TF-IDF.
4. Calculate similarity using Cosine Similarity.
5. Generate a percentage-based matching score.
6. Provide recommendations based on the results.
